This is the first website I designed and built from scratch, featuring a concept I created to showcase what a coffee shop offers.


This website was built entirely from scratch using only HTML, JavaScript, and custom CSS, without the use of any frameworks. The concept is based on a local coffee shop in La Union. All the elements, from the colors, logo, design, and up to contents, I created all of them. During the development process, I encountered challenges, particularly with CSS, which helped me better appreciate the efficiency and convenience that CSS frameworks provide.
