This project is a collaborative output for one of my subjects, where we were tasked to select an existing NGO based in Pampanga.


This project is a full-stack website built using the MEAN stack. It showcases the organization’s mission and purpose, while also digitizing its initial Google Forms for volunteer applications. An admin dashboard was also developed, allowing administrators to view and manage volunteer applicants.
